# Provider branding

`google-g.png` is Google's official color G, downloaded from https://developers.google.com/static/identity/images/g-logo.png on 2026-09-08. Source and usage guidance: https://developers.google.com/identity/branding-guidelines.

Clarity's vector mark is rendered by `components/ui/clarity-mark.tsx` from the original app icon artwork in `assets/app.icon/Assets/icon-speech.svg`. The Apple sign-in glyph uses the installed Hugeicons Pro solid rounded package.
